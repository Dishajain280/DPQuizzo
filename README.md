# 🧩 Dynamic Quiz Website

An interactive quiz platform built with **HTML, CSS, and JavaScript**.  
Users can answer multiple-choice questions, get instant feedback, track their score, and view results — all without page reloads.

---

## 🚀 Project Goal

Build a dynamic quiz website where users can:

- **Answer questions** with instant feedback  
- **Track score** live during the quiz  
- **Use a timer system** for each question  
- **View final results** with performance messages  
- **Restart quiz** to try again  
- *(Optional)* Save progress using LocalStorage  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript (main focus)  
- LocalStorage (optional for persistence)  

---

## ✨ Core Features

### 1️⃣ Start Quiz Screen
- User clicks **Start Quiz**  
- JavaScript loads the first question dynamically  

---

### 2️⃣ Multiple Choice Questions
- Display **4 options per question**  
- Click → instant feedback (correct/wrong)  
- Highlight answers using JS  

---

### 3️⃣ Score Tracking
- Score increases for correct answers  
- Display **live score** during quiz  

---

### 4️⃣ Timer System
- 10–15 seconds per question  
- Auto-next when time ends  
- Implemented using **setInterval()**  

---

### 5️⃣ Result Page
- Show **final score**

  - Good 🙂
